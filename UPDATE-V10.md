# MyNumerologyCharts V10

## Main value features added

- Mobile-first result action panel.
- Preview a branded result card before sharing or downloading.
- Download the result card as PNG.
- Download the result card as JPG.
- Share the result through the device share menu where supported.
- Share fallback copies a result summary and website link.
- Print-friendly full dashboard for browser PDF saving.
- Save up to 50 charts privately on the current device.
- Open or delete saved charts from a responsive Saved Charts panel.
- Share cards omit the full birth date and full birth name.

## Responsive behaviour

- Two-column action grid on normal mobile screens.
- Single-column action grid at 390px and below.
- Preview and saved-chart dialogs fit within the mobile viewport.
- Buttons wrap instead of extending beyond the screen.
- Desktop and tablet layouts remain supported.
