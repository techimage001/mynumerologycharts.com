# Known limitations

- Pythagorean numerology only in formula version 1.0.
- Latin A to Z name mapping; transliteration can change non-Latin names.
- The print command uses the browser's native PDF capability rather than bundling a PDF library.
- Local profiles remain on the current browser and are not synchronised across devices.
- PHP mail is a placeholder until authenticated SMTP is configured on Hostinger.
- Browser-rendered, SMTP, PHP/SQLite and live Hostinger tests still require deployment testing.
